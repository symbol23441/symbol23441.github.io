xv6操作系统启动过程

本文深入讲解了 xv6 操作系统在 RISC-V 架构下通过 QEMU 裸机启动的全过程。内容包括从 QEMU 加载内核映像开始，到 _entry 汇编入口设置早期栈，再到 start() 中完成特权级切换，以及 main() 函数中内核各模块的初始化，直至第一个用户进程的运行、/init 与 shell 的启动。

QEMU虚拟机启动内核详细如下

1. QEMU 裸机启动内核

QEMU虚拟机以裸机方式运行 xv6，不使用 BIOS、bootloader 或 OpenSBI模拟：

  • 使用参数 -bios none -kernel kernel
  • QEMU 会将内核 ELF 映像加载到物理地址 0x80000000。
  • 由kernel.ld 明确设置程序段_entry放在0x80000000地址上，确保 QEMU 启动后能正确跳转。
  • 每个 CPU核心均从此开始执行。

2. _entry：汇编入口（entry.S）

_entry程序段(entry.S) 在内核启动早期，主要作用: 初始化C语言所需栈环境。

因为C语言运行必须依赖栈，如函数调用、局部变量、返回地址等都用到栈。

在 _entry 中：

  • 为每个 CPU 分配一个临时栈 stack0（定义在 start.c静态代码段，.bss 位置固定，每个核一个 4KB栈）
  • 设置好栈后，通过 call start 进入内核的 C 启动逻辑

OS初始化完毕后，后续的栈均通过页表机制来分配，内核栈和用户栈。

3. start()：M-mode 切换到 S-mode（start.c）

start() 在 Machine 模式（M-mode） 下运行，主要作用是为 S-mode 准备运行环境与相关权限。

通过设置mepc（机器模式异常程序寄存器）为main地址，通过mret（伪程序返回）跳转到main运行。这样跳转的原因涉及 RISC-V 的特权级机制。

包括：

  • 设置 mstatus.MPP = S-mode，准备通过 mret 进入 S-mode
  • 设置 mepc = main，即跳转目标地址
  • 关闭页表（satp = 0）
  • 委托中断和异常给 S-mode（medeleg / mideleg）
  • 开放 PMP（物理内存访问权限）给 S-mode
  • 设置 mtvec = timervec，开启定时器中断（用于调度器）
  • 把当前 hart ID 写入 tp 寄存器，供后续 cpuid() 快速访问

最后通过 mret 指令切换到 S-mode，开始执行 main() 函数。

采用如下mret跳转，而不用call、ecall 的原因是什么?

这是 RISC-V 架构中 唯一安全、标准的方法，用于从 M-mode 切换到 S-mode。不能直接 call main()，否则操作系统将在错误特权级下运行，可能进行非法访问或导致系统异常。

例如：mstatus 是 RISC-V 中用于记录处理器当前状态的 64 位控制寄存器，负责管理中断使能、特权级切换等，是操作系统实现异常处理与模式切换的核心机制。S-mode 下对 mstatus 的访问受限，通常使用其子集 sstatus，该寄存器包含与 S-mode 相关的低位字段，如 SIE、SPIE、SPP、FS、XS、SUM 等。

4. main()：S-mode 内核初始化（main.c）

在S-Mode下 ，内核在 hart 0（主核）完成所有模块初始化，包括相关数据结构、锁、寄存器：

  • 初始化控制台（UART0）和 printf

  • 初始化物理页分配器、内核页表（并开启分页）、进程表、trap（中断/异常）向量、PLIC（中断控制器）

    、 buffer cache、inode 表、文件表、virtio 磁盘驱动

  • 启动第一个用户进程：调用 userinit()

其它 CPU核心等待hart 0初始化完成后，只进行本地硬件相关初始化，如寄存器。

所有核心初始化完成后均进入调度器，进行进程调度。

5. userinit()：启动第一个用户进程

  • 创建一个内核进程结构（proc）
  • 将 initcode 二进制数组写入用户地址空间（准确说是一段指定程序启动进程）
  • 设置该进程为 RUNNABLE

该进程启动后，调用 exec("/init") 加载文件系统中的 /init ELF 文件，进入真正的 init 用户程序。

6. /init：引导 shell 与僵尸进程处理

  • /init 是后台进程，它会 fork() 出一个子进程运行 sh（shell）
  • 自身则进入无限循环调用 wait()，用于清理孤儿进程（僵尸回收）
  • 如果 sh 退出，init 会重启它，保持系统有交互能力

7. shell：进入用户交互界面

  • 用户通过 shell 交互执行命令（如 ls, cat, echo）。可创建新的用户进程，由内核调度和执行

至此，xv6 内核已完成初始化。

附页：

RISC-V特权级：

RISC-V 多种特权级用于保护系统不同层级的资源：

模式 名称 用途
M-mode Machine 模式 最底层，启动时默认在此模式，能访问所有 CSR 和硬件资源
S-mode Supervisor 模式 操作系统运行模式，访问受限，管理用户程序
U-mode User 模式 普通用户程序，权限最低
